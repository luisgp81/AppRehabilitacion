# Contexto de impresión 3D de Luis
- Impresora: **Elegoo Centauri Carbon** (CoreXY cerrada, cama 256×256×256 mm, boquilla 0,4 mm de acero endurecido, PEI texturizada, firmware tipo Klipper).
- Cama: zona excluida X 246–256, Y 0–20.
- El G-code debe usar el start/end G-code oficial de Elegoo para la CC (ver `articulado/cc_pla.ini`).
- Las figuras son para que juegue Kiran: robustas, sin aristas finas y articuladas si procede.
- Entregar siempre el `.gcode` listo para el pendrive, además del STL.
